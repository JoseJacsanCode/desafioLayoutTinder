# Desafio de Layout — Tinder 💘

Projeto Flutter desenvolvido como um desafio de UI, com o objetivo de recriar a interface (layout) do aplicativo **Tinder** utilizando widgets nativos do Flutter.

A proposta é treinar construção de telas, componentização e organização visual em um app multiplataforma, reproduzindo elementos característicos do Tinder como cards de perfil, botões de ação e estrutura de navegação.

## 🚀 Tecnologias

- [Flutter](https://flutter.dev/)
- [Dart](https://dart.dev/)

## 📁 Estrutura do projeto

```
├── assets/      # Imagens e recursos visuais (ex.: logo.png)
├── lib/         # Código-fonte da aplicação (telas e widgets)
└── pubspec.yaml # Dependências e configurações do projeto
```

## ✅ Pré-requisitos

- [Flutter SDK](https://docs.flutter.dev/get-started/install) instalado e configurado
- Um emulador/dispositivo (Android, iOS) ou navegador, dependendo da plataforma de destino

## ▶️ Como executar

```bash
# Clone o repositório
git clone https://github.com/JoseJacsanCode/desafioLayoutTinder.git

# Acesse a pasta do projeto
cd desafioLayoutTinder

# Instale as dependências
flutter pub get

# Rode o projeto (escolha o dispositivo/emulador desejado)
flutter run
```
